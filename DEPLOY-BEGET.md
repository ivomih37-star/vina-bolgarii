# Публикация на Beget (хостинг с Apache)

Инструкция по заливке сайта `kvistrade.ru` на **Beget** через
файловый менеджер панели управления. Beget работает на Apache/Nginx,
поэтому вместо Cloudflare-файлов `_headers`/`_redirects` используется
`.htaccess` (уже в архиве).

> Архив для загрузки: `kvis-trade-beget.zip` собирается командой
> `python3 build.py && zip -r kvis-trade-beget.zip index.html about.html
> privacy.html terms.html cookie.html .htaccess sitemap.xml robots.txt
> favicon.ico apple-touch-icon.png assets/logo assets/photos assets/catalogs`

---

## Этап 1. Загрузка файлов (10 минут)

1. Войти в панель: https://cp.beget.com
2. Раздел **«Файловый менеджер»**.
3. Перейти в папку сайта:
   `~/kvistrade.ru/public_html/` (или та, что привязана к домену —
   у Beget обычно `public_html` внутри папки с именем сайта).
4. Если внутри лежат стандартные заглушки Beget
   (`index.html` с рекламой, `.htaccess`) — удалить их.
5. Кнопка **«Загрузить файлы»** → выбрать `kvis-trade-beget.zip`.
6. После загрузки: правый клик по архиву → **«Извлечь»** (Extract).
   Всё содержимое должно оказаться **прямо в `public_html/`**, а не
   во вложенной папке. Если распаковалось в подпапку — переместить
   файлы на уровень выше.
7. Удалить сам `kvis-trade-beget.zip` после распаковки.

Проверка структуры — в `public_html/` должно быть:
```
public_html/
├── index.html
├── about.html  privacy.html  terms.html  cookie.html
├── .htaccess          ← важно! включает HTTPS и заголовки
├── sitemap.xml  robots.txt
├── favicon.ico  apple-touch-icon.png
└── assets/
    ├── logo/     (логотип, favicon-*)
    ├── photos/   (заглушка — сюда фото продукции)
    └── catalogs/ (заглушка — сюда PDF-каталоги)
```

> `.htaccess` — файл скрытый. Если он не виден в файловом менеджере,
> включить показ скрытых файлов (шестерёнка/настройки вида).

## Этап 2. Привязать домен и включить HTTPS (10 минут)

1. Панель Beget → **«Домены и поддомены»**.
2. Убедиться, что `kvistrade.ru` привязан к папке `kvistrade.ru`
   (site root = `public_html`). Если домен ещё не заведён —
   **«Добавить домен»**, указать `kvistrade.ru`.
3. Раздел **«SSL-сертификаты»** → выбрать `kvistrade.ru` →
   выпустить бесплатный **Let's Encrypt**. Выпуск занимает 5–15 минут.
4. После выпуска сертификата HTTPS-редирект в `.htaccess` начнёт
   работать автоматически (правило `HTTP → HTTPS`).

> ⚠️ Пока сертификат не выпущен, правило форса HTTPS будет кидать
> на несуществующий https и сайт «не откроется». Либо сначала
> выпусти SSL, либо временно закомментируй блок «HTTP → HTTPS»
> в `.htaccess` и раскомментируй после выпуска.

## Этап 3. DNS (если домен не на Beget)

Если `kvistrade.ru` зарегистрирован не в Beget, надо направить его
на Beget одним из способов:
- **A-запись** домена → IP, указанный в панели Beget
  (раздел «Домены» показывает IP сервера), **или**
- сменить **NS** домена на NS Beget (`ns1.beget.com`, `ns2.beget.com`,
  `ns1.beget.pro`, `ns2.beget.pro`) у текущего регистратора.

Распространение DNS: от 15 минут до 24 часов.

## Обновление сайта в будущем

При правках: `python3 build.py` локально → пересобрать zip → залить
и распаковать в `public_html` (перезаписав старые файлы). Либо через
FTP-клиент (FileZilla): данные FTP — в панели Beget, раздел «FTP».

> Автодеплой из GitHub у Beget из коробки нет (в отличие от Cloudflare
> Pages — см. `DEPLOY.md`). Если нужен автодеплой, это отдельная
> настройка (webhook + скрипт на сервере) или переход на Cloudflare.
