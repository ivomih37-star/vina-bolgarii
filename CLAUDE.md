# Проект: Сайт «Вина Болгарии» (КВИС ТРЕЙД)

## О проекте
Лендинг (одностраничный сайт) официального представителя болгарских
производителей вин и крепких напитков на российском рынке. Бренд
представительства — **КВИС ТРЕЙД**.

Представляемые винодельни:
- **Katarzyna Estate** — премиальные красные вина, долина Фракии.
- **Black Sea Gold** — белые, игристые, мускаты; Поморие, черноморское побережье.
- **SIS Industries** — крепкие напитки: бренди, ракия, дистилляты.

Целевой рынок: Россия. Аудитория: рестораны, винотеки, дистрибьюторы.
Язык сайта: русский.

## Настроение и стиль
Тёплое, гастрономическое, премиальное «винное».
- Палитра: бордо (`#4a1320`), терракота (`#b9542d`), золото (`#c8a24a`),
  тёплый пергамент (`#f6efe2`). Все цвета вынесены в CSS-переменные `:root`.
- Шрифты (Google Fonts): Prata (заголовки), Forum (надписи капсом),
  Manrope (основной текст). Все с поддержкой кириллицы.
- Брейкпоинт адаптивности — `860px` (меню, графика и сетки переключаются
  в одну колонку).

## Сборка: как устроены файлы сайта
Сайт собирается из шаблона и конфига — **редактировать `index.html`
напрямую не нужно**, он перезаписывается при каждой сборке.

- `index.template.html` — исходник сайта (HTML + CSS + JS в одном файле),
  с плейсхолдерами вида `{{BRAND_TITLE}}`, `{{EMAIL}}`, `{{PHONE_TEL}}` и
  маркерами-комментариями `<!--HERO_VISUAL-->…<!--/HERO_VISUAL-->`,
  `<!--GASTRO_VISUAL-->…<!--/GASTRO_VISUAL-->` для замены CSS-графики на фото.
  **Все правки контента и вёрстки делать здесь.**
- `site.config.json` — реальные данные: бренд (`brand_title`, `brand_html`),
  контакты (`email`, `phone_display`, `phone_tel`), пути к фото
  (`hero_photo`, `gastro_photo`; пустая строка = оставить нарисованную
  CSS-графику) и ссылки на PDF-каталоги по каждой винодельне
  (`katarzyna_catalog_url`, `blacksea_catalog_url`, `sis_catalog_url`;
  пустая строка = кнопка превращается в «Запросить по почте» с mailto).
- `build.py` — собирает `index.html` из шаблона и конфига. Запуск:
  `python build.py` (нужен только Python 3, без зависимостей). Параметры
  `--config` / `--template` / `--out` позволяют переопределить пути.
  Скрипт предупреждает в stderr, если фото/каталог из конфига не найден
  на диске или в шаблоне остался незаполненный плейсхолдер.
- `index.html` — **сгенерированный файл**, открывается прямо в браузере
  без сервера. После любой правки `index.template.html` или
  `site.config.json` нужно перезапустить `build.py`, чтобы изменения
  попали сюда.
- `create-site.sh` / `create-site.ps1` — автономные генераторы, с нуля
  создающие структуру проекта (папки `assets/`, цельный `index.html` без
  шаблонов) в произвольной директории. Это отдельный инструмент
  «бутстрап с нуля», а не часть обычного workflow правок — трогать только
  если просят пересоздать проект целиком.
- `README.md` — инструкция для владельца сайта (не разработчика): как
  установить Claude Code и пересобрать сайт.

### Типичный workflow правки контента/вёрстки
1. Менять `index.template.html` (текст, секции, CSS, JS).
2. Если меняются контакты/бренд/фото/каталоги — менять `site.config.json`.
3. Запустить `python build.py`.
4. Проверить результат в `index.html` открытием в браузере.

## Структура секций (`index.template.html`)
По порядку на странице: возрастной гейт (`#ageGate`, 18+) → навигация
(`#nav`) → манифест бренда (`#manifesto`) → винодельни (`#producers`) →
позиционирование (`#positioning`) → каталоги PDF (`#catalogs`) →
гастро-сочетания (`#gastro`) → процесс работы с дистрибьютором (`#process`)
→ контакты/CTA (`#contact`).

## Папки
- `assets/photos/` — фотографии (бутылки, виноградники, блюда). Сейчас
  только плейсхолдер-файл, реальных фото пока нет — `hero_photo` /
  `gastro_photo` в конфиге пустые, поэтому используется нарисованная
  CSS-графика.
- `assets/logo/` — логотип КВИС ТРЕЙД (`kvis-trade.png`,
  `kvis-trade-gold.png`), уже подключён через `brand_html` в конфиге.
- `assets/catalogs/` — сюда кладутся PDF-каталоги виноделен; пока пусто,
  кнопки каталогов работают как «Запросить по почте».

## Что нужно доделать (приоритет)
1. **Добавить реальные фото** — бутылка и бокал в hero/gastro-блоках до
   сих пор нарисованы CSS (поля `hero_photo`/`gastro_photo` в
   `site.config.json` пустые). Положить фото в `assets/photos/`, прописать
   пути в конфиге, пересобрать.
2. **Залить PDF-каталоги** виноделен в `assets/catalogs/` и прописать пути
   в `site.config.json` (`katarzyna_catalog_url` и т.д.), иначе кнопки
   остаются как mailto-запрос.
3. **Проверить тексты о винодельнях** — описания правдоподобные, но факты
   (год основания, награды, сорта) нужно сверить с производителями.

Контакты и бренд уже реальные (КВИС ТРЕЙД, `kvistrade@gmail.com`,
`+7 916 243-23-96`) — заданы в `site.config.json`, отдельно их менять
в HTML не нужно.

## Договорённости для правок
- Не ломать существующую цветовую палитру и набор шрифтов без запроса.
- Весь текст интерфейса — на русском.
- Сохранять адаптивность: на экране уже 860px меню и часть графики скрываются.
- Править `index.template.html` и `site.config.json`, а не `index.html`
  напрямую — он пересоздаётся при каждой сборке и прямые правки потеряются.
- Шаблон/сайт остаётся цельным HTML-файлом (HTML+CSS+JS вместе) — не
  разбивать на отдельные файлы без причины.

## Подпроект `biar-outreach/`
Отдельный, не связанный со сборкой сайта инструмент: агентный pipeline
для холодного B2B-аутрича (скоринг лидов HoReCa → поиск контактов →
письма на русском → деплой через ESP, по умолчанию DRY_RUN). У него своя
документация — `biar-outreach/CLAUDE.md` — и свои skills/agents/hooks в
`biar-outreach/.claude/`. Если задача касается аутрич-кампании, смотреть
туда, а не в этот файл.
