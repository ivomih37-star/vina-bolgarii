# Проект: Сайт «Вина Болгарии»

## О проекте
Лендинг (одностраничный сайт) официального представителя болгарских
производителей вин и крепких напитков на российском рынке.

Представляемые винодельни:
- **Katarzyna Estate** — премиальные красные вина, долина Фракии.
- **Black Sea Gold** — белые, игристые, мускаты; Поморие, черноморское побережье.
- **SIS Industries** — крепкие напитки: бренди, ракия, дистилляты.

Целевой рынок: Россия. Аудитория: рестораны, винотеки, дистрибьюторы.
Язык сайта: русский.

## Настроение и стиль
Тёплое, гастрономическое, премиальное «винное».
- Палитра: бордо (`#4a1320`), терракота (`#b9542d`), золото (`#c8a24a`),
  тёплый пергамент (`#f6efe2`). Все цвета вынесены в CSS-переменные `:root`.
- Шрифты (Google Fonts): Prata (заголовки), Forum (надписи капсом),
  Manrope (основной текст). Все с поддержкой кириллицы.

## Структура файлов
- `index.html` — весь сайт (HTML + CSS + JS в одном файле).
- `assets/photos/` — сюда класть фотографии бутылок, виноградников, блюд.
- `assets/logo/` — логотип представительства, если появится.

## Что нужно доделать (приоритет)
1. **Заменить CSS-заглушки на реальные фото** — сейчас бутылка и бокал
   нарисованы кодом. Поставить профессиональную съёмку продукции.
2. **Проверить тексты о винодельнях** — описания правдоподобные, но факты
   (год основания, награды, сорта) нужно сверить с производителями.
3. **Указать реальные контакты** — почта и телефон в кнопках и подвале
   сейчас условные (`info@example.com`, `+7 000 000-00-00`).
4. **Бренд** — заголовок «Вина Болгарии» можно заменить на название
   представительства.

## Договорённости для правок
- Не ломать существующую цветовую палитру и набор шрифтов без запроса.
- Весь текст интерфейса — на русском.
- Сохранять адаптивность: на экранах уже 860px меню и часть графики скрываются.
- Файл цельный (один index.html) — не разбивать на отдельные файлы без причины.
