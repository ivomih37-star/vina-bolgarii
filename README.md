# Вина Болгарии — сайт

Одностраничный сайт представительства болгарских вин и крепких напитков.

## Как посмотреть сайт
Откройте файл `index.html` двойным щелчком — он откроется в браузере.
Ничего устанавливать не нужно.

## Как продолжить работу в Claude Code

Claude Code — это помощник, который работает с этой папкой прямо в терминале
вашего компьютера и вносит правки по вашим текстовым просьбам.

### 1. Установить
Самый простой способ (без дополнительных программ):

- **macOS / Linux** — откройте Терминал и вставьте:
  ```
  curl -fsSL https://claude.ai/install.sh | bash
  ```
- **Windows** — откройте PowerShell и вставьте:
  ```
  irm https://claude.ai/install.ps1 | iex
  ```

Проверить, что установилось:
```
claude --version
```

### 2. Открыть проект
В терминале перейдите в эту папку и запустите Claude Code:
```
cd путь/к/папке/vina-bolgarii
claude
```
При первом запуске он попросит войти в аккаунт Anthropic (нужна активная
подписка Claude Pro/Max или аккаунт с кредитами).

### 3. Что писать
Claude Code сам прочитает файл `CLAUDE.md` и поймёт, что это за проект.
Дальше можно просить обычными словами, например:
- «Замени нарисованную бутылку на фото из assets/photos/bottle.jpg»
- «Поставь реальные контакты: почта sales@…, телефон +7…»
- «Добавь раздел с отзывами ресторанов»
- «Сделай отдельную страницу-каталог с позициями вин»

## Папки
- `assets/photos/` — фотографии (бутылки, виноградники, блюда)
- `assets/logo/` — логотип
