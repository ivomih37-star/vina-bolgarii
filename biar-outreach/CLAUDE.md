Это **рабочий контекст агента** для B2B-развития КВИС ТРЕЙД. Ты (Claude) общаешься с
оператором в чате и ведёшь **account-based** проработку импортёров:


## Правила пайплайна
1. **Источник — ручной/ресёрч CSV импортёров** (`importers.csv`, профили в `2-importers-research.md`).
2. **Оценка импортёра** — по `1-importer-criteria.md` (6 факторов → приоритет P1/P2/P3) +
   матрица «производитель→импортёр».
3. **Презентация** — досье-питч под импортёра по `3-presentation-frameworks.md`; письмо-запрос
   встречи проходит `legal-auditor` (`0-legal-constraints.md`).
4. **Контакты ЛПР** — вручную (`4-outreach-notes.md`), без рабочего контакта в отправку не идёт.
5. **Отправка — только DRY_RUN** (`DRY_RUN=true`): реально не шлём. Включается осознанно.
6. Реальные SKU/факты/цифры всегда `⚠️ проверить` у производителя. Ключи — только в `.env`.

## Артефакты (папка outputs/)
- `importers-matrix.csv` — пары производитель×импортёр с fit-баллом и приоритетом.
- `importer-contacts.csv` — импортёры с ЛПР и контактом.
- `presentations/<импортёр>.md` — досье-питч под конкретного импортёра.

## Как запустить
Команда `/run-matching` — профиль импортёров → матрица → контакты → досье.
Скиллы в `.claude/skills/` Claude вызывает по шагам сам.
