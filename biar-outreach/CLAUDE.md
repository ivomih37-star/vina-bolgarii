
## Тон писем
Тёплый, гастрономический, премиальный. Говорим про терруар, историю винодельни,
гастро-сочетания, эксклюзивность и прямой контракт с производителем. НЕ используем
масс-маркетинговые штампы, «скидки», «акции», CAPS, спам-слова.

## Правила пайплайна
1. **Источник лидов — ручной CSV** (см. `2-leads-sources.md`). Платный 2ГИС/Контур API
   пока за флагом и не вызывается (`USE_2GIS=false`).
2. **Скоринг** — строго по `1-scoring-criteria.md`, 6 факторов → тир A/B/C.
3. **Письма** — по `3-copy-frameworks.md`, на русском, под тир. Каждое письмо обязано
   пройти `legal-auditor` (см. `0-legal-constraints.md`).
4. **Отправка — только DRY_RUN** по умолчанию (`DRY_RUN=true`): ничего реально не шлём,
   пишем превью в `outputs/`. Реальная отправка включается оператором осознанно.
5. Никогда не клади реальные ключи в репозиторий — только в `.env` (он в `.gitignore`).

## Артефакты (папка outputs/)
- `horeca-scored.csv` — список точек с тиром и обоснованием.
- `contacts.csv` — точки с найденным ЛПР и email.
- `email-sequences.md` — готовые персональные серии писем.
- `pipeline-log` — лог всех вызовов (пишет хук).

## Как запустить
Команда `/run-campaign` — полный прогон от CSV до превью писем.
Скиллы в `.claude/skills/` Claude вызывает по шагам сам.
