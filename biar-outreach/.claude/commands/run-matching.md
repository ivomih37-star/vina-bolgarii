# Команда: run-matching

Прогони account-based пайплайн BIAR. Источник: `$1` (по умолчанию `importers.csv`).
Отправки нет — DRY_RUN.

## Шаги
1. **Загрузка импортёров** — `load_importers($1)`. Покажи, сколько загружено.
2. **Профиль/скоринг** — скилл `profile-importers` → приоритет P1/P2/P3 по `1-importer-criteria.md`.
3. **Матрица соответствия** — скилл `match-producers` → `outputs/importers-matrix.csv`
   (производитель×импортёр, fit, приоритет).
4. **Контакты ЛПР** — скилл `find-lpr` → `outputs/importer-contacts.csv`. Без контакта — `needs_contact`.
5. **Досье-питч** — скилл `build-presentation`: на каждого P1/P2 досье
   `outputs/presentations/<импортёр>.md` + письмо-запрос встречи (через `legal-auditor`).

## Итог оператору
Сводка: сколько импортёров по приоритетам, какие пары производитель→импортёр в P1,
пути к матрице и досье. Напомни: факты `⚠️ проверить`, отправки нет (DRY_RUN).
