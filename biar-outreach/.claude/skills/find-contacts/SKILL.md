# Скилл: find-contacts

Дополняет отскоренные точки контактом лица, принимающего решение.

## Шаги
1. Возьми `outputs/horeca-scored.csv` (тиры A/B/C, без `skip`).
2. Для точек без `email`/`contact_name`:
   - попроси оператора дополнить вручную (сайт точки, соцсети, 2ГИС), ИЛИ
   - используй поля, уже заполненные в исходном CSV.
   На 🟢-старте контакты собираем руками — массового энричмента по API нет.
3. Цель контакта по тиру: A — сомелье/управляющий; B — бар-менеджер; C — закупщик/опт.
4. Запиши `outputs/contacts.csv`: `name,type,city,tier,contact_name,email,phone,notes`.
   Точки без рабочего email помечай `needs_contact` — их в отправку не берём.

## Результат
`outputs/contacts.csv` — точки с верифицированным ЛПР и email, готовы для write-sequence.
