# Скилл: score-icp

Оценивает каждую точку из списка лидов и присваивает тир.

## Шаги
1. Загрузи лиды: `python lib/leads_client.py <путь-к-csv>` или `load_from_csv()`.
2. Для каждой точки примени рубрику из `../../1-scoring-criteria.md` (6 факторов, 0–2 балла).
3. Посчитай сумму → тир: A (9–12), B (5–8), C (0–4 или профиль бар/опт).
   Дистрибьютор/опт — всегда минимум C. Не-HoReCa — `skip`.
4. Запиши результат в `outputs/horeca-scored.csv` с колонками:
   `name,type,city,tier,score,reason` (reason — 1 строка обоснования).
5. Сложные/пограничные кейсы можно делегировать субагенту `icp-scorer`.

## Результат
`outputs/horeca-scored.csv` — список с тирами, готов для этапа find-contacts.
