# Скилл: profile-importers

Оценивает каждого импортёра на соответствие нашим производителям.

## Шаги
1. Загрузи: `python lib/importers_client.py importers.csv` или `load_importers()`.
2. Для каждого примени критерии из `../../1-importer-criteria.md` (6 факторов, 0–2 балла).
3. Посчитай сумму → приоритет: P1 (9–12), P2 (5–8), P3 (0–4).
   Own-brand мультинационалы → P3.
4. Запиши промежуточно для следующего шага (match-producers).
5. Сложные кейсы — субагенту `importer-analyst`.

## Результат
Оценённый список импортёров с приоритетом — вход для `match-producers`.
