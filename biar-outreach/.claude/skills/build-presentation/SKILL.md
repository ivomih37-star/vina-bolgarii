# Скилл: build-presentation

Под каждого приоритетного импортёра — персональное досье и письмо-запрос встречи.

## Шаги
1. Для импортёров P1/P2 из матрицы возьми подходящих производителей (high/mid fit).
2. По `../../3-presentation-frameworks.md` собери досье `outputs/presentations/<импортёр>.md`:
   кому/почему → кого предлагаем → коммерческая логика → что просим (встреча/дегустация) → сэмплы.
3. Сгенерируй короткое **письмо-запрос встречи** (не серию касаний). Все факты/SKU — `⚠️ проверить`.
4. **Обязательно** прогони письмо через `legal-auditor` (ФЗ-38/171).
5. Отправки нет — DRY_RUN. Оператор читает досье и решает по встречам.

## Результат
`outputs/presentations/<импортёр>.md` на каждого приоритетного импортёра — готово к встрече.
