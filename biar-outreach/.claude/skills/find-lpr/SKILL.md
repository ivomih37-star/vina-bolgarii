# Скилл: find-lpr

Находит лицо, принимающее решение о новых производителях, у приоритетных импортёров.

## Шаги
1. Возьми импортёров с приоритетом P1/P2 из `outputs/importers-matrix.csv`.
2. По `../../4-outreach-notes.md` определи роль ЛПР (категорийный/портфельный менеджер,
   директор по закупкам, бренд-менеджер по региону).
3. Контакты собираем **вручную** (сайт импортёра, LinkedIn, профильные СМI/мероприятия) —
   попроси оператора дополнить или внеси известное.
4. Запиши `outputs/importer-contacts.csv`:
   `importer,contact_name,role,email,phone,channel,status,notes`.
   Без рабочего контакта — `status=needs_contact` (в отправку не идёт).

## Результат
`outputs/importer-contacts.csv` — ЛПР приоритетных импортёров.
