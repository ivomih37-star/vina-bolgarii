# Выход на ЛПР импортёра (account-based, не массово)

Импортёров мало → работаем точечно. Не рассылка, а адресный выход на нужного человека +
запрос встречи.

## Кто ЛПР в импортёре
- **Категорийный / портфельный менеджер** (вино / крепкое) — решает о новых производителях.
- **Директор по закупкам / development manager** — заводит новые контракты.
- **Бренд-менеджер по региону/стране** — если есть восточноевропейское направление.
- Иногда — коммерческий директор (в небольших компаниях).

## Где искать контакты (🟢 вручную, бесплатно)
- Сайт импортёра — раздел «О компании», «Контакты», «Сотрудничество/поставщикам».
- LinkedIn / профильные мероприятия (Prodexpo, ВиноВод, дегустации).
- Профильные СМИ (WineRetail, Kommersant) — имена топов в интервью.
- Запрос через общую почту/форму «предложить продукцию» — как первый заход.

Заполняем `outputs/importer-contacts.csv`:
`importer,contact_name,role,email,phone,channel,status,notes`.
Без рабочего контакта — статус `needs_contact`, в отправку не идёт.

## Как заходить
1. Сначала **досье-питч** под импортёра (`3-presentation-frameworks.md`) — чтобы письмо
   было предметным.
2. Короткое **письмо-запрос встречи** (не серия касаний — одно адресное письмо + 1 вежливый
   follow-up через неделю).
3. Цель письма — **встреча/дегустация**, не продажа.
4. Все письма — в DRY_RUN (`sender_client`), реально не уходят, пока не решите осознанно.

## Когда дойдёт до реальной отправки
Отдельный домен + почта представительства, аккуратная адресная отправка (не масс-рассылка),
соответствие `0-legal-constraints.md`. ESP здесь вторичен — объём малый, можно и вручную
из почты КВИС ТРЕЙД.

## Классификация ответов
Через `reply-classifier`: `interested` (готовы встретиться) / `callback` / `not_now` / `no`.
`interested` — немедленно готовить встречу и образцы.
