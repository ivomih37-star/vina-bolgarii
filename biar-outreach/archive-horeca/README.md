# archive-horeca — на паузе

Эти файлы относятся к **прямому аутричу в HoReCa** (рестораны, бары, винотеки).
Проект развёрнут на модель **«импортёры-first»** (см. корневой `CLAUDE.md`):
сначала заводим производителей к крупным импортёрам РФ, HoReCa — низ воронки, позже.

Файлы сохранены, чтобы вернуться к HoReCa-направлению, когда импортёр возьмёт портфель
и появится спрос «снизу» (pull-маркетинг). Ничего не удалено.
