# Black Sea Gold Catalog RU — статус проекта

Мастер-каталог продукции Black Sea Gold, русская редакция для KVIS Trade.
Источник: `BSG_Catalog_BODY_Festa_ENG_4_compressed_1pagesdeleted_1.pdf` (32 стр., загружен в чате — не хранится в репозитории).

## Прогресс по этапам

- [x] 1. Перевод — выполнен по всем 32 страницам исходника.
- [x] 2. Проверка соответствия оригиналу — сверено построчно при переводе.
- [ ] 3. Литературная редактура — требуется отдельный проход редактора.
- [ ] 4. Унификация терминологии — черновой словарь готов (`Glossary_Terms.md`), нужна финальная сверка.
- [ ] 5. Подготовка к профессиональной вёрстке.
- [ ] 6. Финальная корректура.

## Файлы

- `Black_Sea_Gold_Catalog_RU.md` — мастер-текст каталога (главы 1–6), источник правды для правок.
- `Black_Sea_Gold_Catalog_RU.docx` — экспорт в docx (pandoc, из .md).
- `Black_Sea_Gold_Catalog_RU.pdf` — экспорт в pdf (pandoc → HTML → печать в PDF через headless Chromium), в цветах и духе фирменного стиля сайта.
- `Glossary_Terms.md` — единый словарь терминов.
- `Black_Sea_Gold_Presentation_RU.pdf` — визуальная презентация (33 стр., альбомная ориентация) в стиле оригинального каталога: цветные развороты, фото бутылок, вырезанные из исходного PDF (та же продукция, та же фотосъёмка производителя), разделители глав, сводка наград. Черновой вариант для встреч/презентаций — не заменяет мастер-каталог `.md`, а визуализирует его.
- `Photos/` — 47 фото бутылок, по одному файлу на позицию каталога, имя файла = название позиции (например, `Special Reserve Merlot.png`, `Burgas 63 12 Years.png`). Извлечены из исходного английского PDF (та же продукция, та же студийная съёмка производителя, фон прозрачный, ~150 dpi — подходит для экрана, презентаций и превью). Для типографской печати большим тиражом со временем нужны оригиналы в высоком разрешении от производителя — см. п. 6 ниже.

## Что нужно доделать (приоритет)

1. **Дозапросить у производителя** карточки продукции для линеек, упомянутых только в таблицах наград: Vera Terra, Villa Marvella, Villa Ponte, Grand Prix Golden Rhythm, Izbata, Pontus 1991, Special Reserve Stamp, Kagor Blagovest.
2. **Уточнить контакты винодельни** Black Sea Gold для Главы 6 (в исходнике не приведены).
3. **Подтвердить контакты KVIS Trade** (kvistrade.ru, im@kvistrade.ru) перед публикацией.
4. **Собрать таблицу наград** в единую сводную форму для вёрстки (сейчас — по конкурсам, как в оригинале).
5. **Литературная редактура** дегустационных описаний — сверка стиля между позициями.
6. **Фото бутылок в высоком разрешении** — 47 позиций в `Photos/` сейчас взяты из исходного PDF (150 dpi, для печати мало). Запросить у производителя оригиналы для типографской вёрстки.
