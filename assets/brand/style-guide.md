# KVIS TRADE — фирменный стиль

Источник: `KVIS_TRADE_Premium_Gateway_2.pdf` (NotebookLM-презентация для
производителей). Документ задаёт визуальный язык бренда; ниже —
выжимка для применения на лендинге `kvistrade.ru` и любых
последующих материалах (письма, презентации, договорные шапки).

## 1. Общее впечатление
Тёмный «премиум-гейтвэй»: чёрный фон + металлическое золото +
тёплый кремовый текст. Тон — B2B, сдержанный, серьёзный,
«эксклюзивный мост к рынку». Никаких ярких цветовых пятен, никаких
изобразительных фотографий — графика монохромная, держится на
золотых линиях, рамках и плашках.

## 2. Палитра
| Роль | HEX | Где |
| --- | --- | --- |
| Фон основной | `#0a0a0a` | поля страниц |
| Фон карточек | `#15151a` | плашки с описанием, рамки-«трофеи» |
| Золото базовое | `#c8a24a` | заголовки, рамки, акценты |
| Золото светлое | `#e9d199` | блики, gradient stop, hover |
| Золото тёмное | `#8a6a2b` | gradient stop, ободки |
| Текст основной | `#f3e9d8` | тело, подписи |
| Текст приглушённый | `rgba(243,233,216,0.65)` | вспомогательный |
| Разделители | `rgba(200,162,74,0.35)` | тонкие золотые линии |

Текущий лендинг уже использует `#c8a24a` (gold) — это совпадает с
презентацией. Меняется фон (с тёплого пергамента `#f6efe2` на
угольно-чёрный) и инверсия светлоты текста.

## 3. Типографика
- **Заголовки уровня H1 / cover**: serif с засечками, ВЕРСАЛЬНЫЕ,
  с лёгким межбуквенным разрядом, заливка золотом. PDF использует
  стиль, близкий к Trajan / Cormorant SC / Cinzel.
  *Веб-замена:* `Cormorant SC` (Google Fonts) — поддерживает кириллицу,
  даёт нужные «римские» пропорции.
- **Подзаголовки**: тот же serif, кириллический капс, белый/золотой.
- **Body**: humanist sans-serif. PDF — близко к Lato / Open Sans.
  *Веб:* остаёмся на `Manrope` — он уже есть на лендинге и закрывает
  кириллицу/цифры.
- **Микро-шапки на плашках**: уменьшенный capslock золотом с трекингом
  ≈ 0.15em (см. стр. 4: «Дълбоко разбиране», «Гарантиран резултат»).

## 4. Графические мотивы
1. **Логотип-узел** (стр. 1): переплетённый монограммный знак золотом
   на чёрном — сильный «вензельный» мотив. Используется уменьшенно
   на остальных страницах как декоративный watermark в углах.
2. **Золотые рамки / трофеи**: тонкая золотая обводка (1px) + лёгкий
   градиент на самой рамке (тёмное золото → светлое золото) — даёт
   «металлический объём». См. стр. 7 (рамка вокруг манифеста) и
   стр. 6 («пьедесталы»).
3. **Лучи из центра**: тонкие линии-«солнце», расходящиеся от
   центрального круглого блока (стр. 4). Можно реализовать чистым
   CSS `conic-gradient` или SVG.
4. **Подвал-разделитель** (стр. 1, низ): центрированная строка
   капсом, светло-золотая, разделители `│`. Формула:
   `«КВИС ТРЕЙД ЕООД │ ОСНОВАНА 2023 │ СОФИЯ, БЪЛГАРИЯ │ МЕЖДУНАРОДНИ СТАНДАРТИ»`.
5. **Иконки**: тонкая контурная графика золотом — корона, ключ,
   витрина, мобильный телефон с QR-кодом (стр. 4, 6). Стиль:
   1.5–2px stroke, скруглённые концы, без заливки.

## 6. Тон и ключевые фразы
- «Стратегически мост към премиум пазара» / «Эксклюзивный
  доступ к премиум-рынку Москвы».
- «Експертен внос и дистрибуция» / «Экспертный импорт и дистрибуция».
- «Концепция "под ключ"» — для блока партнёров.
- «Умна логистика» / «Интелигентен обходен маршрут».
- «Ако Русия е вашата цел, ние сме вашият път» / «Если Россия —
  ваша цель, мы — ваш путь.»

## 7. Что НЕ делать
- Не использовать яркие цветовые пятна (синий, зелёный, красный).
- Не ставить «гастрономические» фото блюд/виноградников на чёрный
  фон без художественной обработки — это ломает премиум-вайб.
- Не смешивать sans-serif капс и serif капс в одном заголовке.
- Не использовать тёплый пергамент `#f6efe2` как фон секций — он
  относится к старой версии лендинга и противоречит фирменному стилю.
